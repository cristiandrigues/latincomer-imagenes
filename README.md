# latincomer-imagenes

Imágenes de productos de Ferretería Latincomer (Caracas) para sus publicaciones en Mercado Libre, latincomer.net y Cashea.

Estructura: `img/<SKU>-<n>.jpg` (n=1 principal, fondo blanco 1200x1200; 2..6 secundarias).
URL pública: `https://raw.githubusercontent.com/cristiandrigues/latincomer-imagenes/main/img/<archivo>`
